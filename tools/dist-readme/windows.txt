E-Rect for Windows (x86-64)
===========================

Run erect.exe. Keep the packs folder next to it - that is where the music and
sound effects live. Without it the game still runs, just silently.

Controls
--------
    Player 1   W A S D, SPACE to attack
    Player 2   arrow keys, ENTER to attack
    Gamepads   supported; pick a scheme per player in Settings
    ESC        pause

    move left/right   walk          jump   leave the ground
    down while airborne             ground slam (puts up the wall)

Settings and high scores go to %APPDATA%\erect\settings.json

Built by cross-compiling from macOS with cargo-zigbuild, and NOT tested on
Windows. It links only against system DLLs, so nothing else needs installing,
but treat the first run as the real test.
